07 · Designing the context

Sandboxes — explicit boundaries for execution

An isolated environment where the agent runs code, bash and tools that act on the world — with verifiable technical boundaries.

BoundaryWhy it matters
Limited filesystemThe agent only accesses the designated working folders
Limited networkAuthorized endpoints only — no exfiltration, no lateral movement
Limited credentialsLeast privilege — the agent has no more access than it needs
Limited timeEvery run expires — prevents infinite loops and silent consumption
Limited resourcesExplicit CPU, memory and disk — prevents accidental denial of service

A sandbox is to agent security what the container is to software deployment. No serious agent runs without one.
